# May Bibiana Osorio Merchán — Portafolio profesional

Portafolio web de una sola página para presentar el perfil, los servicios técnicos, la trayectoria profesional, la formación y algunas publicaciones de **May Bibiana Osorio Merchán**, consultora en salud pública y epidemiología, fonoaudióloga y magíster en Salud Pública.

## Vista general

El sitio está desarrollado en HTML, CSS y JavaScript nativos, sin frameworks ni dependencias de instalación. Es adaptable a móviles y escritorio e incluye animaciones discretas de entrada, navegación por secciones y una identidad visual inspirada en la naturaleza.

### Identidad visual

```css
--color-1: #88EBCF;
--color-2: #9D88EB;
--color-3: #EB88A4;
--color-4: #D6EB88;
```

- Fondo claro de inspiración natural.
- Tipografía: Arial Narrow, con alternativas condensadas.
- Diseño responsive.
- Animaciones respetuosas con `prefers-reduced-motion`.

## Publicación en GitHub Pages

1. Crear un repositorio público en GitHub.
2. Subir `index.html` y `README.md` a la raíz del repositorio.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Elegir la rama `main` y la carpeta `/ (root)`.
6. Guardar y esperar la URL pública que entrega GitHub Pages.

El archivo principal debe llamarse `index.html`.
